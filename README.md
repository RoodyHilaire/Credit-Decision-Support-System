# Credit-Decision-Support-System
Outil analytique de scoring crédit pour l’aide à la décision et le suivi des demandes.


L’outil permet de saisir, via un formulaire simple, les informations principales d’un client.
À partir de ces données, un modèle analytique estime la probabilité de défaut et génère automatiquement une décision de crédit (acceptée ou refusée).

Une fois les variables renseignées, l’utilisateur lance la prédiction.
Le résultat est affiché immédiatement, avec une décision visuelle claire et la probabilité associée, facilitant l’interprétation du score.

L’ensemble des demandes est ensuite enregistré et centralisé dans un tableau de bord.
Celui-ci permet de consulter des indicateurs clés tels que :
le nombre total de demandes,
le nombre de crédits acceptés et refusés,
l’historique des clients avec leurs caractéristiques et la décision correspondante.

Ce prototype démontre comment un modèle de scoring peut être intégré dans un système applicatif afin de structurer la prise de décision, renforcer la traçabilité des demandes et améliorer le reporting.
